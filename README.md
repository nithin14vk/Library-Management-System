A menu-driven Java application to manage books, members, borrowing, and returning books.
# Library Management System

## 1. Problem Statement

Managing books and library members manually can be time-consuming and may lead to errors in tracking borrowed and returned books. This project aims to simplify library operations using a menu-driven Java application.

## 2. Project Description

The Library Management System is a Java-based console application that allows users to manage books and members and perform basic library operations.

## 3. Features

- Add new books.
- Register library members.
- Borrow books.
- Return books.
- Display book details and availability.
- Validate user input and handle errors.

## 4. Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE

## 5. How to Compile and Run

### Using Eclipse IDE

1. Install the Java Development Kit (JDK) and Eclipse IDE.
2. Open Eclipse and select **File → Import → Existing Projects into Workspace**.
3. Select the downloaded project folder.
4. Wait for Eclipse to build the project.
5. Open the main Java class containing the `main()` method.
6. Right-click the file and select **Run As → Java Application**.
7. Follow the menu displayed in the console.
